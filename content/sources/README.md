# Official sources

Downloaded on 2026-10-23. These are the raw materials for Tsinda's lessons and questions.

Each `.txt` file is text extracted from the PDF beside it. Scanned PDFs (2019, 2021, 2022 and the 2024 Ministerial Instructions) have no `.txt` yet because they need OCR.

## past-papers/

These are the official NESA Primary Leaving Exam (P6) papers. They contain **questions only**: NESA does not publish marking guides.

- Source: https://www.nesa.gov.rw/1/resources → Past_Papers
- Subjects: `mathematics`, `english`, `kinyarwanda`, `set` (Science and Elementary Technology), `srs` (Social and Religious Studies)
- 2023–2025 papers are text PDFs. They follow the current format, so start with these.
- 2019, 2021 and 2022 papers are scans.
- 2020 has no papers because there was no exam (COVID). 2021 has no English paper because NESA doesn't publish one.

## nesa/

| File | What it is |
|---|---|
| `paper-standards-2022` | Format and topic weighting for each paper (pp. 5–21). Where it differs from the real 2023–2025 papers, follow the papers. |
| `ministerial-instructions-2024-amendment` | Current grading rules: A = 80–100%, pass = 50%. |
| `results-analysis-2019-2022-*` | National results and examiners' comments. |
| `guide-classroom-and-national-assessment` | How assessment works in Rwanda. |

## reb-2026/

These are REB's revised curriculum files for the 2026/27 school year, which is the year he sits the exam.

- `syllabus-p4-p6/`: units and competences for P4–P6. P4–P6 content can all appear in the PLE.
- `schemes-of-work-p6/`: the term-by-term teaching order for P6.
- Source: https://elearning.reb.rw/course/view.php?id=1806. P6 pupil books and teacher guides are on the same page but were not downloaded.
